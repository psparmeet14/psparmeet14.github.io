# Legacy Static Site Snapshot

This directory contains the original HTML, CSS, and image assets that powered the portfolio before it was converted into a React single-page application. The files are preserved for reference and historical comparison.

- `index.html`, `about.html`, … `contact.html`: Original standalone pages
- `style.css`: Original global stylesheet migrated into `src/assets/style.css`
- `profile-photo.jpg`: Initial profile placeholder image

The active site now lives in the React code under the repository root (`src/`, `public/`). Any updates should be made in the React components; these legacy files should remain untouched unless you want to review the previous implementation.
